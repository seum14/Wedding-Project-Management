# Event Planning & Scheduling | Microsoft Project Case Study

A structured wedding-planning case study covering a 180-day schedule, from 1 January to 30 June 2022. The project demonstrates how a complex event can be broken into tasks, dependencies, resources and milestones.

**Author:** [Khalid Hasan Seum](https://github.com/seum14) · **Tool:** Microsoft Project

## Planning approach

- **Work breakdown structure:** Organises the plan into 11 workstreams.
- **Scheduling:** Defines task sequences, durations, dependencies and milestones.
- **Critical path analysis:** Identifies activities that affect the completion date.
- **Resource planning:** Coordinates responsibilities and resource allocation.
- **Budget considerations:** Incorporates purchasing, bookings and approvals.

## Workstreams

Date and budget planning · Ceremony and reception venues · Guest invitations · Essential purchases · Entertainment · Catering · Photography and video · Transport · Reception coordination · Honeymoon planning · Event-day coordination
